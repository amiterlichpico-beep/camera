# AXIOM Beta - Full Enclosure Concept

## Description
This project features a custom-designed mechanical enclosure and front plate concept for the AXIOM Beta open-source cinema camera. Modeled with high-precision engineering standards in Onshape, the enclosure is designed to protect the internal image sensor, maintain strict optical alignment for the internal lens elements, and provide structural rigidity. The design includes dedicated internal mounting points for structural hardware and integration with an active cooling system.

## How it is used
The CAD models (including the front plate and body components) are exported into standard manufacturing formats like .STEP. These parts can be CNC machined from aluminum or 3D printed using high-density engineering filaments (such as PETG, ABS, or Carbon Fiber PLA). Once manufactured, the front plate is assembled onto the main chassis using M3 and M4 machine screws, enclosing the internal camera modules, active 12V cooling fans, and lens mount hardware.

## Why I made this project
The goal of this project was to design a robust, modular, and production-ready enclosure for open-source hardware. Designing a camera enclosure requires solving specific engineering constraints, such as tight tolerances for optical components, proper thermal dissipation for the processing boards via active cooling fans, and ergonomics. This project serves as a showcase of parametric enclosure design tailored for complex electronic and optical devices.
