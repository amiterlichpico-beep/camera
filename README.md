# AXIOM Beta - Full Enclosure Concept

## Description
This project is a high-precision mechanical enclosure and replica model of the AXIOM Beta cinema camera, designed completely from scratch. It features detailed component modeling, including a custom front plate, integrated internal hardware mounts, and an active cooling system layout. Every part was engineered parametrically to match real-world physical and optical design constraints.

## How it is used
The complete multi-part assembly can be exported into universal manufacturing formats like .STEP. The components are optimized to be CNC machined from aluminum or 3D printed using high-durability filaments (PETG/ABS). Assembly is completed using standard M3 and M4 socket head cap screws to mount the functional front plate, secure the dual 60x60x15mm 12V cooling fans, and enclose the system hardware.

## Why I made this project
I built this project to challenge my parametric modeling skills and study complex device architecture by creating a precise digital twin of an open-source cinema camera, managing tight tolerances and thermal constraints.

## Development Timeline, Hours & Onshape Bug Notice
The very initial document layout and a basic sketch were opened back in October 2024 (taking about 2 hours), but the project was immediately frozen and put on hold due to the war situation. 

The entire 3D camera enclosure, complex parts, and assembly were developed completely from scratch over the summer of 2026, totaling over 100+ hours of intensive CAD engineering during July and August, plus 8 hours of recent documentation and refinement.
